# Security Policy

This tool runs locally, collects no data, sends nothing anywhere, and needs no API key or secret. It only reads the files and folders you name, and it never deletes, moves, or changes a file — it only reports sizes.

If you find a case where the tool changes or deletes a file, follows a link into a folder it was not asked to check, or reports a size that is not the file's real size, please open an issue describing the exact commands and input. Do not include any real secret in the report.
